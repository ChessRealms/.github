# Support

ChessRealms projects are maintained by an open-source community. Support is
provided on a best-effort basis, without guaranteed response or resolution
times.

## Before asking for help

Please check the affected repository's README, documentation, examples, and
existing issues. Make sure you are using a supported version and try the latest
available release when practical.

## Where to ask

- Use the repository's **Discussions** area for usage questions, design
  discussions, and general help when Discussions are enabled.
- Use the repository's **Issues** area for reproducible bugs and concrete
  feature requests.
- Follow the [security policy](https://github.com/ChessRealms/.github/blob/main/SECURITY.md)
  to report a suspected vulnerability. Do not disclose vulnerability details
  in a public discussion or issue.

Choose the repository that owns the affected component. For example, report
chess rules, move generation, or library API problems in
[ChessRealms.Engine](https://github.com/ChessRealms/Engine), and report browser
editor or user-interface problems in
[FEN Editor](https://github.com/ChessRealms/fen-editor).

## Information to include

Help maintainers understand the request by including, when relevant:

- the repository and version or commit you are using;
- your operating system, browser, runtime, and other relevant environment
  details;
- what you were trying to accomplish;
- the expected and actual behavior;
- minimal steps or sample data that reproduce the problem;
- complete error messages, logs, screenshots, or recordings with secrets and
  personal data removed;
- troubleshooting steps you have already tried.

Please keep each discussion or issue focused on one topic. A small,
self-contained reproduction is usually the fastest way to help diagnose a
problem.

## Scope

Maintainers may be unable to provide individual implementation consulting,
debug private applications, or support modified and unsupported versions. The
community can still discuss these topics when someone has the time and context
to help.
