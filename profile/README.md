<h1 align="center">ChessRealms</h1>

<p align="center">
  Open-source chess projects, libraries, and tools.
</p>

## Projects

- **[ChessRealms.Engine](https://github.com/ChessRealms/Engine)** — a .NET library for chess positions, legal move generation, FEN, game history, and standard game rules.
- **[FEN Editor](https://github.com/ChessRealms/fen-editor)** — a browser-based editor for chess positions in FEN notation.

## Contributing

Each project contains its own setup and contribution instructions. Issues and pull requests are welcome in the relevant repository.
