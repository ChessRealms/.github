# ChessRealms brand assets

Primary colors:

- Dark green: `#20332B`
- White: `#FFFFFF`

## SVG

The `svg` directory contains the editable, resolution-independent master files:

- `chessrealms-emblem.svg` — circular emblem with transparent corners.
- `chessrealms-avatar.svg` — square dark background for services that apply their own avatar mask.
- `chessrealms-mark-white.svg` — transparent white monogram for dark backgrounds.
- `chessrealms-mark-dark.svg` — transparent dark monogram for light backgrounds.

## PNG

The `png` directory contains raster exports:

- Emblem and avatar at 32, 48, 64, 128, 256, 512, and 1024 px.
- Transparent white and dark monograms at 1024 px.

Prefer SVG in documentation and websites. Use PNG when a service does not accept SVG. For profile images, use at least 256 px; 32 px is the recommended minimum displayed size.
